# Nexus Display

Nexus Display es una plataforma web orientada a la gestión de un negocio dedicado a la comercialización y distribución de pantallas y repuestos para teléfonos móviles. El sistema permitirá administrar los productos disponibles, sus características y compatibilidad con diferentes modelos de celulares, además de gestionar clientes, inventario y ventas.

La plataforma estará dirigida principalmente a talleres de reparación, técnicos independientes y clientes particulares que requieran adquirir pantallas y repuestos para teléfonos móviles. Desde el sistema se podrá consultar la disponibilidad de productos, registrar clientes y gestionar el proceso de venta de manera organizada.

En la parte administrativa, el sistema permitirá controlar los productos, marcas, modelos de celulares, inventario y ventas realizadas. De esta manera, *Nexus Display* busca centralizar la información del negocio y facilitar el control de sus operaciones comerciales.

## Objetivo del sistema

Desarrollar una plataforma web que permita gestionar de manera organizada los productos, clientes, inventario y ventas de un negocio dedicado a la comercialización y distribución de pantallas y repuestos para teléfonos móviles.
